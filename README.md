# NYEWASCO Smart Attendance System (Phase 1 MVP)

This is the Phase 1 Minimum Viable Product (MVP) for the NYEWASCO Electronic Attendance System.

## 🚀 Key Features
- ✅ **GPS Geofencing:** Live map visualization with PASS/FAIL validation.
- ✅ **Voice-Activated Clock-In:** Say "Clock In" to log attendance.
- ✅ **QR Code Badges:** Auto-generated for each employee.
- ✅ **Supervisor Dashboard:** Real-time stats and live map.
- ✅ **CSV Export:** One-click download for HR/Payroll.
- ✅ **Security:** Hashed passwords and immutable audit logs.
